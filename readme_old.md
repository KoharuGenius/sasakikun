# ノベルゲーム『さっさと帰れ！佐々木君 — 守れ乙女の聖域 —』企画概要

## ■ 基本情報
* **ゲームタイトル**：さっさと帰れ！佐々木君 — 守れ乙女の聖域（サンクチュアリ） —
* **ボリューム（クリア時間）**：約5分〜10分（短編プチノベルゲーム）

---

## ■ キャラクター
* **佐々木（主人公）**
  * 疑似知性派大学生。下心ゼロで「風水・空間地理学における地磁気的聖域（サンクチュアリ）」を大真面目に研究している。
  * 自分の屁理屈を絶対に疑わない図々しさと、謎の万能感を持つ。
* **はるか（ヒロイン）**
  * 佐々木の幼馴染。「乙女のプライベート空間（＝聖域）」を死守したいツンデレ。
  * 佐々木の不条理な理論を論破して追い出そうとするが、毎回彼のペースに巻き込まれる。

---

## ■ 大まかなストーリー
倒叙ミステリ風の不法侵入ツッコミコメディ。

1. **【プロローグ（朝）】**
   はるかのベッドで優雅に目覚める佐々木と、顔を真っ赤にしてブチギレているはるか。
   「なぜ俺は他人のベッドにいるんだ？」という朝の謎（ミステリー）から物語が始まる。
2. **【本編（昨夜の回想）】**
   勝手に上がり込んできた佐々木。「この202号室は奇跡的な地磁気が流れる聖域（サンクチュアリ）だ」と主張し、居座りを決め込む。
3. **【分岐とオチ】**
   はるかは佐々木を追い出すべく抵抗するが、その暴走がトリガーとなり佐々木が即効催眠／気絶。そのままベッドを占領されて朝を迎える。

## 選択肢
```
■一回目の「帰れ」：選択肢３つ
・帰る場所がない
・雨だから帰れない
・努力がもったいない（MPが切れた）

■二回目の「帰れ」：選択肢３つ（ただし全部結果は、「幼児化」で同じ）
・帰らない
・帰らない
・帰らない

■三回目の最終通告的な「帰れ」：選択肢４つ
・汚部屋・黒歴史エンド用選択肢
・ガチゲーマーエンド用選択肢
・怪談ルートエンド用選択肢
・爆睡ルートエンド用選択肢
```

## ■ 四種類のエンド

### 1. 汚部屋・黒歴史ノートルート
* **佐々木の動機**：
  部屋の散らかりを「地磁気の流れを遮る空間の目詰まり」と判定。聖域のエネルギーを循環させるための「環境クリーンアップ」を開始する。
* **はるかの抵抗（不条理トリガー）**：
  隠していた中二病時代のポエムノートを読まれそうになり、ヤケクソでそこに書かれた「暗黒の封印呪文」を迫真の演技で詠唱する。
* **寝かせる経緯（オチ）**：
  佐々木の脳に黒歴史の波動がダイレクトアタック。「我が精神が……実家のベッドへ引きずり込まれる……！」とトランス状態になり、そのままベッドへ倒れ込む。

### 2. ガチゲーマールート
* **佐々木の動機**：
  「聖域の加護で集中力が増し、視界にゲーミングPCのような虹色オーラが見える」と主張。聖域であることの証明として格ゲー勝負を持ちかける。
* **はるかの抵抗（不条理トリガー）**：
  100連敗してブチギレ、コントローラーを奪うために部屋にあった「強力害虫スプレー」を佐々木に向けて全開噴射する。
* **寝かせる経緯（オチ）**：
  スプレーの霧を吸い込んだ佐々木が「ふぅ……このアロマ、実家のリビングと同じ匂いがする……」と謎のバグを起こし、多幸感に包まれながらそのまま爆睡する。

### 3. 怪談ルート
* **佐々木の動機**：
  部屋に溜まった負の湿気（陰の気）を散らすため、怪談話による「ショック療法（毒をもって毒を制す）」で邪気を払おうとする。
* **はるかの抵抗（不条理トリガー）**：
  怖すぎてパニックになり、大好きなオタク作品の魔王キャラの決め台詞「泥の如く眠れ、愚民め！！」をプロ級の迫真演技で一喝する。
* **寝かせる経緯（オチ）**：
  圧巻の威圧感が直撃し、「……はい、お母さん……」と幼少期の記憶がフラッシュバックして完全沈黙。そのまま気絶するように泥のように眠る。

### 4. 爆睡ルート
* **佐々木の動機**：
  人間（自分）をアンテナに見立て、ベッドで横たわることで「生体バリア」を展開し、聖域の波動を部屋に定着させようとする。
* **はるかの抵抗（不条理トリガー）**：
  居座り続ける佐々木を物理的に排除するため、首元に「筋膜リリース（マッサージ）ガン」を全開で叩きつける。
* **寝かせる経緯（オチ）**：
  奇跡的に「人間の即効睡眠ツボ」へジャストヒット。佐々木が電源の切れたロボットのようにそのままベッドへ崩れ落ちる。
